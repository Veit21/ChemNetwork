## Useful commands
### Macos
Start MongoDB 'kernel' to be able to save to DB
````
brew services start mongodb/brew/mongodb-community
````
Check running services
````
brew services list
````
Shut down MongoDB 'kernel'
````
brew services stop mongodb/brew/mongodb-community
````
Find more information about MongoDB and PyMongo in the [official docs](https://www.mongodb.com/docs/languages/python/pymongo-driver/current/get-started/).
